# CheburNet

**CheburNet** — это автономный сервис, который ежедневно скачивает родительский список VLESS‑серверов, автоматически фильтрует российские узлы, проверяет корректность строк и публикует итоговый файл `cheburnet.txt` в этом репозитории.

Проект работает полностью автоматически:
скачивание → фильтрация → валидация → обновление файла → коммит.

## 🧩 Что делает скрипт

- скачивает родительский список VLESS‑конфигураций
- выделяет только российские узлы
- проверяет корректность каждой строки
- формирует чистый список `cheburnet.txt`
- ведёт лог обновлений (`update.log`)
- автоматически коммитит изменения в репозиторий

## ⚙ Режимы запуска

### Однократный запуск (для cron или ручного обновления)

`node update.js`

Скрипт выполнит обновление один раз и завершит работу.

---

### Фоновый режим (daemon)

`node update.js --daemon`

Скрипт будет работать как автономный демон, выполняя обновление раз в сутки.

Чтобы демон не блокировал терминал, его следует запускать в фоне средствами оболочки.

---

## 🚀 Запуск демона в фоне

### Termux / Android

`nohup node update.js --daemon > daemon.log 2>&1 &`

### Linux / macOS

`node update.js --daemon > daemon.log 2>&1 &
disown`

### Windows PowerShell

`Start-Process node -ArgumentList "update.js --daemon"`

---

## 🔍 Проверка, что демон работает

### Termux / Linux / macOS

`ps aux | grep update.js`

Если демон активен, в выводе будет строка с `node update.js --daemon`.

### Windows PowerShell

`Get-Process node`

---

## 📝 Логи демона

Все события записываются в:

`update.log`

А вывод фонового процесса — в:

`daemon.log`
