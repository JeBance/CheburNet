# CheburNet

**CheburNet** — это автономный сервис, который ежедневно скачивает родительский список VLESS‑серверов, автоматически фильтрует российские узлы, проверяет корректность строк и публикует итоговый файл `cheburnet.txt` в этом репозитории.

Проект работает полностью автоматически:
скачивание → фильтрация → валидация → обновление файла → коммит.

## 🧩 Что делает скрипт

- скачивает родительский список VLESS‑конфигураций  
- выделяет только российские узлы  
- проверяет корректность каждой строки  
- формирует чистый список `cheburnet.txt`  
- ведёт лог обновлений (`update.log`)  
- автоматически коммитит изменения в репозиторий  

---

## 📦 Источник данных и благодарность автору

Проект **CheburNet** использует открытый список VLESS‑конфигураций из родительского репозитория:

**https://github.com/zieng2/wl**

Если вам полезен этот проект, вы можете поддержать автора оригинального списка — это поможет ему продолжать работу и развивать инфраструктуру.

## ⚙ Автоматизация

Скрипт `update.js` может запускаться вручную или по cron.  
Он не требует вмешательства и работает в полностью автономном режиме.
